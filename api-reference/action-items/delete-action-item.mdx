---
title: 'Delete Action Item'
api: 'DELETE /api/v1/action-items/{id}'
description: 'Delete an action item'
---

## Path Parameters

<ParamField path="id" type="string" required>
  Action item UUID
</ParamField>

## Response

Returns `200 OK`. The action item and its related subtasks/entity mappings are permanently deleted.

<ResponseField name="success" type="boolean" />
<ResponseField name="data" type="object">
  <ResponseField name="id" type="string">UUID of the deleted item</ResponseField>
</ResponseField>
