---
title: 'Ingest Call Recording'
api: 'POST /api/v1/calls/recording/ingest'
description: 'Ingest a call recording URL for automatic transcription and analysis'
---

## Overview

Ingest a call recording URL. The API will automatically transcribe the recording via Deepgram (if no transcript is provided), upload to R2 storage, and create the associated call, interaction, and participant records.

## Request Body

<ParamField body="externalCallId" type="string" required>
  External unique ID from call provider
</ParamField>

<ParamField body="recordingUrl" type="string" required>
  URL to the call recording audio file
</ParamField>

<ParamField body="providerKey" type="string">
  Integration provider key. Defaults to `"api"`.
</ParamField>

<ParamField body="title" type="string">
  Call title
</ParamField>

<ParamField body="direction" type="string">
  Call direction. One of: `inbound`, `outbound`, `unknown`
</ParamField>

<ParamField body="status" type="string">
  Call status. One of: `completed`, `missed`, `voicemail`, `failed`, `busy`, `cancelled`, `unknown`
</ParamField>

<ParamField body="fromNumber" type="string">
  Phone number the call originated from
</ParamField>

<ParamField body="toNumber" type="string">
  Phone number the call was made to
</ParamField>

<ParamField body="durationSeconds" type="number">
  Call duration in seconds
</ParamField>

<ParamField body="ringDurationSeconds" type="number">
  Ring duration before answer
</ParamField>

<ParamField body="startTimestamp" type="string">
  Call start time (ISO 8601)
</ParamField>

<ParamField body="endTimestamp" type="string">
  Call end time (ISO 8601)
</ParamField>

<ParamField body="customer" type="object">
  Customer info: `{ phone?, email?, name? }`
</ParamField>

<ParamField body="orgUnitId" type="string">
  Single org unit ID
</ParamField>

<ParamField body="orgUnitIds" type="array">
  Array of org unit IDs
</ParamField>

<ParamField body="metadata" type="object">
  Additional metadata
</ParamField>

<ParamField body="transcript" type="string">
  Pre-provided transcript. If provided, Deepgram transcription is skipped.
</ParamField>

<ParamField body="language" type="string">
  Language code for transcription
</ParamField>

<ParamField body="deepgramModel" type="string">
  Deepgram model to use for transcription
</ParamField>

<ParamField body="enqueuePreanalyze" type="boolean">
  Whether to enqueue pre-analysis job
</ParamField>

<ParamField body="skipUpload" type="boolean">
  Whether to skip uploading to R2 storage
</ParamField>

<ParamField body="userEmail" type="string">
  Email of the user associated with this call
</ParamField>

<ParamField body="externalCompanyId" type="string">
  External company ID to associate the call with
</ParamField>

## Example Request

```bash
curl -X POST https://api.arali.ai/api/v1/calls/recording/ingest \
  -H "Authorization: Api-Key YOUR_STATIC_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "externalCallId": "call_12345",
    "recordingUrl": "https://recordings.example.com/call_12345.mp3",
    "title": "Sales Follow-up Call",
    "direction": "inbound",
    "status": "completed",
    "fromNumber": "+1-555-123-4567",
    "toNumber": "+1-555-987-6543",
    "durationSeconds": 300,
    "customer": {
      "phone": "+1-555-123-4567",
      "name": "John Doe"
    }
  }'
```
