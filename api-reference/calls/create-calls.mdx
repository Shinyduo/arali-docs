## Overview

Pushes call records from your dialer or CRM into Arali. Send one call or a batch (up to 100 per request is a good size).

- **Rep:** set `assignedUserEmail` to the rep's email; it is matched to the Arali user with that email.
- **Team:** the call is placed in the rep's team automatically. If the rep isn't found, it goes to your workspace's top-level team. You only need `orgUnitId` to override this.
- **Contact:** the call is linked to a contact by `customer.phone` / `customer.email`, or exactly by `contactId`.
- **Duplicates:** re-sending a call with the same `providerKey` + `externalCallId` does not create a duplicate.

- **Transcript:** if you have the call's transcript, send it in `transcript`. Arali stores it and analyses it instead of transcribing the recording. You can also send it later by re-sending the call with the same `externalCallId`.

Required scope: `calls:write`.

## Request Body

<ParamField body="providerKey" type="string" required>
  Identifies the source of the calls (e.g. `aircall`, `twilio`, or your own key such as `manual`). Together with `externalCallId` it de-duplicates calls.
</ParamField>

<ParamField body="skipWorkflows" type="boolean" default="false">
  Don't trigger workflows for these calls. Use for bulk imports of historical calls.
</ParamField>

<ParamField body="calls" type="array" required>
  Array of call objects to create

  <Expandable title="Call Object">
    <ParamField body="externalCallId" type="string" required>
      Your unique ID for the call
    </ParamField>

    <ParamField body="direction" type="string" default="unknown">
      `inbound` or `outbound`
    </ParamField>

    <ParamField body="status" type="string">
      Call outcome. Not connected: `no_answer`, `busy`, `failed`, `abandoned`. Connected: `connected` (Arali refines it to `conversation`, `voicemail`, `ivr` or `gatekeeper` when it analyses the recording).
    </ParamField>

    <ParamField body="startTimestamp" type="string">
      Call start time, ISO 8601 (e.g. `2026-10-22T10:15:00Z`). If omitted, the time the request is received is used.
    </ParamField>

    <ParamField body="endTimestamp" type="string">
      Call end time, ISO 8601
    </ParamField>

    <ParamField body="durationSeconds" type="number">
      Talk time in seconds
    </ParamField>

    <ParamField body="ringDurationSeconds" type="number">
      Ring time before answer, in seconds
    </ParamField>

    <ParamField body="fromNumber" type="string">
      Number the call came from (E.164, e.g. `+919800000000`)
    </ParamField>

    <ParamField body="toNumber" type="string">
      Number the call went to (E.164)
    </ParamField>

    <ParamField body="recordingUrl" type="string">
      Publicly reachable URL of the call recording
    </ParamField>

    <ParamField body="skipAnalysis" type="boolean" default="false">
      Store `recordingUrl` as is and play it from your URL: no upload, transcription or AI analysis (including of a provided `transcript`).
    </ParamField>

    <ParamField body="transcript" type="string">
      The call transcript as text: one turn per line as `Speaker: text` (e.g. `Agent: …` / `Customer: …`), or WEBVTT. Each turn shows as a separate line on the call page. The recording is not transcribed when a transcript is sent.
    </ParamField>

    <ParamField body="language" type="string" default="en">
      Language of the transcript (e.g. `en`, `hi`)
    </ParamField>

    <ParamField body="customer" type="object">
      The other party: `{ phone?, email?, name? }`. Used to link the call to a contact.
    </ParamField>

    <ParamField body="contactId" type="string">
      Arali contact UUID to link the call to. Skips matching by phone/email.
    </ParamField>

    <ParamField body="assignedUserEmail" type="string">
      Email of the rep who made or took the call
    </ParamField>

    <ParamField body="assignedUserId" type="string">
      Arali user UUID of the rep. Takes priority over `assignedUserEmail`.
    </ParamField>

    <ParamField body="orgUnitId" type="string">
      Optional. Arali team (org unit) UUID, overriding the rep's team.
    </ParamField>

    <ParamField body="orgUnitIds" type="array">
      Optional. Several team UUIDs.
    </ParamField>

    <ParamField body="dispositionId" type="string">
      UUID of the call disposition
    </ParamField>

    <ParamField body="title" type="string">
      Call title (generated if omitted)
    </ParamField>

    <ParamField body="metadata" type="object">
      Any extra fields you want stored with the call (e.g. your CRM record IDs)
    </ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Whether the request was processed
</ResponseField>

<ResponseField name="summary" type="object">
  <Expandable title="Summary Object">
    <ResponseField name="total" type="integer">Total calls processed</ResponseField>
    <ResponseField name="success" type="integer">Successfully created</ResponseField>
    <ResponseField name="failed" type="integer">Failed</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="results" type="array">
  One result per call: `externalCallId`, `status` (`success` / `skipped` / `error`), and `callId` / `interactionId` or `reason`
</ResponseField>

## Example Request

```bash
curl -X POST https://api.arali.ai/api/v1/calls \
  -H "Authorization: Api-Key YOUR_STATIC_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "providerKey": "manual",
    "calls": [
      {
        "externalCallId": "call_12345",
        "direction": "outbound",
        "status": "connected",
        "startTimestamp": "2026-10-22T10:15:00Z",
        "endTimestamp": "2026-10-22T10:18:02Z",
        "durationSeconds": 182,
        "ringDurationSeconds": 12,
        "fromNumber": "+919800000000",
        "toNumber": "+919811111111",
        "recordingUrl": "https://recordings.example.com/call_12345.mp3",
        "transcript": "Agent: Hi, this is Riya from Acme.\nCustomer: Hello, yes.\nAgent: Is now a good time to talk?",
        "language": "en",
        "customer": { "phone": "+919811111111", "name": "Jane Doe" },
        "assignedUserEmail": "rep@yourcompany.com",
        "metadata": { "crmLeadId": "LEAD-789" }
      }
    ]
  }'
```
