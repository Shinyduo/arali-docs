---
title: 'Get Call'
api: 'GET /api/v1/calls/{id}'
description: 'Get a single call record by ID'
---

## Overview

Returns the call record together with its participants, recordings and — when
one exists — its **full transcript**, including every speaker-attributed,
timestamped segment. No separate transcript endpoint is required.

## Path Parameters

<ParamField path="id" type="string" required>
  Call UUID **or** the `interaction_id` of the call. Both resolve to the same
  record, so an id taken from an interaction timeline can be used directly.
</ParamField>

## Response

<ResponseField name="success" type="boolean" />

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="id" type="string">Call UUID</ResponseField>
    <ResponseField name="interaction_id" type="string">
      The interaction this call belongs to
    </ResponseField>
    <ResponseField name="participants" type="array">
      Participants, resolved to Arali users or contacts where known
    </ResponseField>
    <ResponseField name="orgUnitIds" type="array">Org units this call is mapped to</ResponseField>
    <ResponseField name="transcript" type="object">
      Present whether or not a transcript exists — when none does, `segmentCount`
      is `0` and `segments` is empty.
      <Expandable title="properties">
        <ResponseField name="id" type="string">Transcript UUID</ResponseField>
        <ResponseField name="language" type="string">Detected language</ResponseField>
        <ResponseField name="fullText" type="string">
          The entire transcript as one block, without speaker attribution
        </ResponseField>
        <ResponseField name="segmentCount" type="integer">Number of segments</ResponseField>
        <ResponseField name="segments" type="array">
          <Expandable title="properties">
            <ResponseField name="id" type="string">Segment UUID</ResponseField>
            <ResponseField name="startMs" type="integer">Start offset in milliseconds</ResponseField>
            <ResponseField name="endMs" type="integer">End offset in milliseconds</ResponseField>
            <ResponseField name="timestamp" type="string">
              `startMs` formatted as `HH:MM:SS`
            </ResponseField>
            <ResponseField name="speakerName" type="string">
              Resolved speaker — the Arali user's name where the participant is
              known, otherwise the display name, otherwise the raw diarised
              label. Falls back to `Unknown`.
            </ResponseField>
            <ResponseField name="text" type="string">What was said</ResponseField>
            <ResponseField name="participantId" type="string">
              Participant this segment is attributed to, when resolved
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

## Required Scopes

`calls:read` or `calls:write`.
