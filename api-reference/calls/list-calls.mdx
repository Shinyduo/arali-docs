---
title: 'List Calls'
api: 'GET /api/v1/calls'
description: 'Get all call records for your enterprise with optional filtering'
---

## Overview

Returns a paginated list of call records for your enterprise with optional filtering by status, direction, company, account, contact, date range, and more.

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results per page. Maximum is 100.
</ParamField>

<ParamField query="status" type="string">
  Filter by call status. One of: `completed`, `missed`, `voicemail`, `failed`, `busy`, `cancelled`, `unknown`
</ParamField>

<ParamField query="direction" type="string">
  Filter by direction. One of: `inbound`, `outbound`, `unknown`
</ParamField>

<ParamField query="start_date" type="string">
  Filter calls starting on or after this date (ISO 8601). Also accepts `startDate`.
</ParamField>

<ParamField query="end_date" type="string">
  Filter calls ending on or before this date (ISO 8601). Also accepts `endDate`.
</ParamField>

<ParamField query="search" type="string">
  Search by call title (case-insensitive partial match). Also accepts `q`.
</ParamField>

<ParamField query="provider" type="string">
  Filter by integration provider (e.g. `aircall`, `twilio`, `nooks`)
</ParamField>

<ParamField query="providerKey" type="string">
  Filter by integration provider key
</ParamField>

<ParamField query="participant_only" type="boolean">
  When `true`, return only calls where the requesting user is a participant
</ParamField>

<ParamField query="date_range" type="string">
  Relative date range filter. Examples: `7d`, `30d`
</ParamField>

<ParamField query="org_unit_id" type="string">
  Filter by org unit UUID
</ParamField>

<ParamField query="user_id" type="string">
  Filter by user UUID
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Whether the operation was successful
</ResponseField>

<ResponseField name="data" type="array">
  Array of call objects
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata
</ResponseField>
