description: 'Get all companies for your enterprise with optional filtering and pagination'
---

## Overview

Returns a paginated list of companies for your enterprise. Each company in the response is enriched with its **stage details** and **custom field values**.

You can filter companies by stage, custom field values, or external company ID. Multiple filters are combined with AND logic.

## Query Parameters

<ParamField query="externalCompanyId" type="string">
  Filter to find a specific company by your custom internal ID.
</ParamField>

<ParamField query="stageKey" type="string">
  Filter by stage key(s). Supports comma-separated values for multiple stages.
  Keys must match a `key` in the `stage_definitions` table.

  **Examples:**
  - `?stageKey=lead` — companies in the "lead" stage
  - `?stageKey=lead,customer` — companies in either "lead" or "customer" stage
</ParamField>

<ParamField query="stageId" type="string">
  Filter by stage definition UUID(s). Supports comma-separated UUIDs.
  Can be combined with `stageKey` (results are intersected).
</ParamField>

<ParamField query="fields[fieldKey]" type="string">
  Filter by custom field values. Replace `fieldKey` with the actual field key
  from your `field_definitions` table.

  Multiple field filters are **AND-ed** — a company must match **all** specified filters.
  Matching is **case-insensitive** for text and enum fields.

  **Examples:**
  - `?fields[tier]=enterprise` — companies where the "tier" field is "enterprise"
  - `?fields[tier]=enterprise&fields[region]=us` — companies matching both fields
  - `?fields[customer_subtype]=Group Dealer` — companies with a specific enum value

  > [!NOTE]
  > **Using n8n, axios, or other HTTP clients?** Tools that use the `qs` library (including n8n's HTTP Request node) automatically parse `fields[key]` as a nested object. The API handles both formats:
  >
  > **Format 1 — curl / raw URL:**
  > ```
  > ?fields[customer_subtype]=Group Dealer
  > ```
  >
  > **Format 2 — n8n "Using JSON" mode** (set the key with brackets as-is):
  > ```json
  > {
  >   "fields[customer_subtype]": "Group Dealer",
  >   "limit": "200"
  > }
  > ```
  >
  > Both are supported. To find your exact `fieldKey` values, call `GET /api/v1/fields/definitions?entityType=company`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of results per page. Maximum is 200.
</ParamField>

## Examples

### Filter by stage

```bash
# Companies in the "customer" stage
GET /api/v1/companies?stageKey=customer

# Companies in either "lead" or "qualified" stage
GET /api/v1/companies?stageKey=lead,qualified
```

### Filter by custom fields

```bash
# Companies where tier = "enterprise"
GET /api/v1/companies?fields[tier]=enterprise

# Companies where tier = "enterprise" AND region = "us"
GET /api/v1/companies?fields[tier]=enterprise&fields[region]=us
```

### Combine filters with pagination

```bash
# Page 2 of customers in the "enterprise" tier, 25 per page
GET /api/v1/companies?stageKey=customer&fields[tier]=enterprise&page=2&limit=25
```
