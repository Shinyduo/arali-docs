---
title: 'List Contacts'
api: 'GET /api/v1/contacts'
description: 'Get all contacts for your enterprise with optional filtering'
---

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number to return. Must be greater than 0.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of results per page. Maximum is 200.
</ParamField>

<ParamField query="search" type="string">
  Search contacts by name, title, external contact ID, email, phone, or normalized phone.
</ParamField>

<ParamField query="q" type="string">
  Alias for `search`.
</ParamField>

<ParamField query="phone" type="string">
  Look up contacts by phone number using digits-only normalization.
</ParamField>

<ParamField query="email" type="string">
  Look up contacts by exact email address.
</ParamField>

<ParamField query="company_id" type="string">
  Filter by company UUID.
</ParamField>

<ParamField query="stage" type="string">
  Filter by contact stage key or stage definition UUID.
</ParamField>

<ParamField query="key_role_user_id" type="string">
  Filter by assigned key-role user UUID. Supports comma-separated values.
</ParamField>

<ParamField query="key_role_key" type="string">
  Filter by key role key. Supports comma-separated values.
</ParamField>

<ParamField query="fields[fieldKey]" type="string">
  Filter by custom field value. Replace `fieldKey` with the custom field key, for example `fields[jenga]=Flexcar`.
  Multiple field filters are AND-combined.
</ParamField>

<ParamField query="sort" type="string">
  Sort field. Supported core fields are `id`, `fullName`, `title`, `externalContactId`, `createdAt`, `updatedAt`,
  `lastActivityAt`, and `lastAssignedAt`.
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort direction for `sort`. Use `asc` or `desc`.
</ParamField>

<ParamField query="sort_by" type="string">
  Alias for `sort`.
</ParamField>

<ParamField query="sort_order" type="string">
  Alias for `order`.
</ParamField>

<ParamField query="sorts" type="string">
  HubSpot-style sort value. Prefix with `-` for descending order, for example `sorts=-createdate`.
  Supported aliases include `createdate` for `createdAt` and `lastmodifieddate` for `updatedAt`.
</ParamField>

## Sorting Custom Fields and Key Roles

Use `field:<fieldKey>` to sort by a custom field value:

```bash
GET /api/v1/contacts?sort=field:jenga&order=asc
```

Use `key_role:<roleKey>` to sort by the active assigned user's name for a key role:

```bash
GET /api/v1/contacts?sort=key_role:manager&order=asc
```

Use `key_role_assigned_at:<roleKey>` to sort by when the active key role assignment started:

```bash
GET /api/v1/contacts?sort=key_role_assigned_at:manager&order=desc
```

## Examples

Filter by a core contact column and sort by a core column:

```bash
curl "https://arali-backend-production.up.railway.app/api/v1/contacts?search=akshat&sort=createdAt&order=desc&limit=10" \
  -H "x-api-key: YOUR_API_KEY"
```

Filter and sort by a custom field:

```bash
curl "https://arali-backend-production.up.railway.app/api/v1/contacts?fields%5Bjenga%5D=Flexcar&sort=field:jenga&order=asc&limit=10" \
  -H "x-api-key: YOUR_API_KEY"
```

Filter by key role user and sort by key role assignment time:

```bash
curl "https://arali-backend-production.up.railway.app/api/v1/contacts?key_role_user_id=USER_ID&key_role_key=manager&sort=key_role_assigned_at:manager&order=desc&limit=10" \
  -H "x-api-key: YOUR_API_KEY"
```

Use HubSpot-style sorting:

```bash
curl "https://arali-backend-production.up.railway.app/api/v1/contacts?sorts=-createdate&limit=10" \
  -H "x-api-key: YOUR_API_KEY"
```

<ResponseField name="success" type="boolean">
  Whether the operation was successful
</ResponseField>

<ResponseField name="data" type="array">
  Array of lightweight contact objects. Use `GET /api/v1/contacts/{id}` for full enriched contact details.
</ResponseField>

<ResponseField name="meta" type="object">
  <Expandable title="Meta Object">

    <ResponseField name="count" type="integer">Number of contacts returned in this response</ResponseField>
    <ResponseField name="page" type="integer">Current page number</ResponseField>
    <ResponseField name="limit" type="integer">Results per page</ResponseField>
    <ResponseField name="totalPages" type="integer">Total number of pages for the current filters</ResponseField>
    <ResponseField name="hasMore" type="boolean">Whether another page is available</ResponseField>

  </Expandable>
</ResponseField>
