---
title: 'List Deals'
api: 'GET /api/v1/deals'
description: 'Get all deals for your enterprise with optional filtering'
---

## Overview

Returns a list of enriched deals for your enterprise with optional filtering by company, account, and pipeline.

## Query Parameters

<ParamField query="limit" type="integer" default="100">
  Number of results per page. Maximum is 200.
</ParamField>

<ParamField query="companyId" type="string">
  Filter by company UUID.
</ParamField>

<ParamField query="accountId" type="string">
  Filter by account UUID.
</ParamField>

<ParamField query="pipelineId" type="string">
  Filter by pipeline UUID.
</ParamField>

<ParamField query="search" type="string">
  Search by deal name (case-insensitive partial match).
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  Whether the operation was successful
</ResponseField>

<ResponseField name="count" type="integer">
  Total number of matching deals
</ResponseField>

<ResponseField name="data" type="array">
  Array of enriched deal objects. Each object has the same shape as the `GET /api/v1/deals/{id}` response.
</ResponseField>

<ResponseField name="search" type="string | null">
  The search query used, if any
</ResponseField>
