---
title: 'Update Deal'
description: 'Update a single deal by ID'
---

<Note>
  The `PUT /api/v1/deals/{id}` endpoint is not implemented. To update a deal, use the [POST /api/v1/deals](/api-reference/deals/create-deals) batch upsert endpoint. Provide either the deal `id` or an `externalDealId` in the deal object to update an existing record.
</Note>
