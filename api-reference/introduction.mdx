## Base URL

All API requests should be made to:

```
https://api.arali.ai
```

## API Version

The current API version is `v1`. All endpoints are prefixed with `/api/v1`.

## Authentication

All endpoints require static API keys:

```bash
Authorization: Api-Key <api_key>
```

See the [Authentication](/authentication) page for more details.

## Response Format

### Success Response (Single Record)

```json
{
  "success": true,
  "data": { ... }
}
```

### Success Response (Batch Operation)

```json
{
  "success": true,
  "summary": {
    "total": 10,
    "success": 8,
    "failed": 2
  },
  "results": [
    {
      "externalId": "hubspot_12345",
      "companyId": "uuid",
      "status": "success"
    },
    {
      "externalId": "hubspot_67890",
      "status": "skipped",
      "reason": "Missing required field: name"
    }
  ]
}
```

## Error Responses

All endpoints return consistent error responses:

<ResponseField name="error" type="string" required>
  Error message describing what went wrong
</ResponseField>

<ResponseField name="details" type="string">
  Additional details about the error
</ResponseField>

<ResponseField name="schema" type="string">
  Reference to the schema endpoint for documentation
</ResponseField>

### HTTP Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `201` | Created |
| `400` | Bad Request - Invalid input |
| `401` | Unauthorized - Invalid or missing token |
| `403` | Forbidden - Insufficient permissions |
| `404` | Not Found - Resource doesn't exist |
| `500` | Internal Server Error |

### Example Error Response

```json
{
  "error": "Missing required fields",
  "details": "Request must include: companies (array)",
  "schema": "GET /api/v1/companies/schema for full documentation"
}
```
