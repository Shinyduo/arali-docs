---
title: 'Get Role Assignment'
api: 'GET /api/v1/key-role-assignments/{assignmentId}'
description: 'Retrieve a specific role assignment by ID'
---

## Path Parameters

<ParamField path="assignmentId" type="string" required>
  The unique ID of the role assignment to retrieve. Must be a valid UUID.
</ParamField>

## Example Request

```bash
curl -X GET https://api.arali.ai/api/v1/key-role-assignments/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Api-Key YOUR_STATIC_KEY"
```

## Response

Returns the role assignment record with full details including:
- Assignment ID
- Role key
- Entity type (`company`, `account`, `contact`, or `deal`)
- Internal entity ID
- Assigned user ID
- Tenure start date
- Tenure end date (if applicable)
- Created and updated timestamps

## Errors

- `400` — Invalid `assignmentId` (must be a valid UUID)
- `404` — Assignment not found
