---
title: 'List Role Assignments'
api: 'GET /api/v1/key-role-assignments'
description: 'Retrieve all internal team assignments or filter by entity or role'
---

## Query Parameters

<ParamField query="entityType" type="string">
  Filter by entity type: `company`, `account`, or `contact`
</ParamField>

<ParamField query="entityId" type="string">
  Filter by the internal Arali UUID of the entity. Takes precedence over `externalEntityId` if both are provided.
</ParamField>

<ParamField query="externalEntityId" type="string">
  Filter by specific customer entity's external ID (requires `entityType` to be set). Ignored if `entityId` is also provided.
</ParamField>

<ParamField query="roleKey" type="string">
  Filter by role key (e.g. `csm`, `ae`, `tam`). Looked up from key role definitions — returns a `400` if the role key doesn't exist.
</ParamField>

<ParamField query="userId" type="string">
  Filter by the internal Arali UUID of the assigned team member.
</ParamField>

## Example Requests

### Get All Role Assignments
```bash
curl -X GET https://api.arali.ai/api/v1/key-role-assignments \
  -H "Authorization: Api-Key YOUR_TOKEN"
```

### Get All Team Members Assigned to a Company (by External ID)
```bash
curl -X GET "https://api.arali.ai/api/v1/key-role-assignments?entityType=company&externalEntityId=acme-corp" \
  -H "Authorization: Api-Key YOUR_TOKEN"
```

### Get All Team Members Assigned to a Company (by Internal ID)
```bash
curl -X GET "https://api.arali.ai/api/v1/key-role-assignments?entityType=company&entityId=00f65964-5129-4eac-b88e-285d4096fe83" \
  -H "Authorization: Api-Key YOUR_TOKEN"
```

### Get All Team Members Assigned to an Account
```bash
curl -X GET "https://api.arali.ai/api/v1/key-role-assignments?entityType=account&externalEntityId=acme-enterprise-account" \
  -H "Authorization: Api-Key YOUR_TOKEN"
```

### Get All CSM Assignments
```bash
curl -X GET "https://api.arali.ai/api/v1/key-role-assignments?roleKey=csm" \
  -H "Authorization: Api-Key YOUR_TOKEN"
```

### Get All Companies Assigned to a Specific Team Member
```bash
curl -X GET "https://api.arali.ai/api/v1/key-role-assignments?roleKey=csm&userId=888843a2-8d54-4716-a44b-718ebb6a00f2" \
  -H "Authorization: Api-Key YOUR_TOKEN"
```

## Response

Returns an array of role assignment records with:
- Assignment ID
- Key role definition ID (use `roleKey` filter to query by human-readable key)
- Entity type and internal entity ID
- Assigned user ID (internal team member)
- Tenure start and end dates
- Timestamps
