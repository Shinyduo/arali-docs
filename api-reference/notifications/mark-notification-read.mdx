---

## Path Parameters

<ParamField path="id" type="string" required>
  Notification UUID
</ParamField>

## Example Request

```bash
curl -X POST https://api.arali.ai/api/v1/notifications/NOTIFICATION_UUID/read \
  -H "Authorization: Bearer YOUR_JWT"
```

## Response

<ResponseField name="success" type="boolean">
  Whether the operation was successful
</ResponseField>
