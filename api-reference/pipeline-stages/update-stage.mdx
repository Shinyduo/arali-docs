---

<Note>
  PUT `/api/v1/pipeline-stages/{id}` is **not implemented**.

  To update a pipeline stage, use **POST `/api/v1/pipeline-stages`** (batch upsert) and include the `id` field in the stage object you want to update.
</Note>
