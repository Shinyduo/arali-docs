title: 'Update Pipeline'
api: 'PUT /api/v1/pipelines/{id}'
description: 'Update a single pipeline by ID'
---

<Note>
  PUT `/api/v1/pipelines/{id}` is **not implemented**.

  To update a pipeline, use **POST `/api/v1/pipelines`** (batch upsert) and include the `id` field in the pipeline object you want to update.
</Note>
