## Path Parameters

<ParamField path="key" type="string" required>
  The unique key of the plan to retrieve
</ParamField>

## Example Request

```bash
curl -X GET https://api.arali.ai/api/v1/plans/{key} \
  -H "Authorization: Api-Key YOUR_STATIC_KEY"
```

## Response

Returns the plan record with full details including:
- Plan ID
- Key
- Name
- Description
- Status
- External Plan ID
- Pricing configuration
- Associated products
- Created and updated timestamps
