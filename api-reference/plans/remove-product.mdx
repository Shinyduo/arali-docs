---
title: 'Remove Product from Plan'
api: 'DELETE /api/v1/plans/{key}/products/{productKey}'
description: 'Remove a product from a specific plan by key'
---

## Path Parameters

<ParamField path="key" type="string" required>
  The unique key of the plan
</ParamField>

<ParamField path="productKey" type="string" required>
  The key of the product to remove from the plan
</ParamField>

## Example Request

```bash
curl -X DELETE https://api.arali.ai/api/v1/plans/{key}/products/{productKey} \
  -H "Authorization: Api-Key YOUR_STATIC_KEY"
```

## Response

Returns a success confirmation upon removal.
