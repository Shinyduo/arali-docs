---
title: 'Get Product'
api: 'GET /api/v1/products/{key}'
description: 'Retrieve a specific product by key'
---

## Path Parameters

<ParamField path="key" type="string" required>
  The unique key of the product to retrieve
</ParamField>

## Example Request

```bash
curl -X GET https://api.arali.ai/api/v1/products/{key} \
  -H "Authorization: Api-Key YOUR_STATIC_KEY"
```

## Response

Returns the product record with full details including:
- Product ID
- Key
- Name
- Description
- Kind
- Status
- Billable candidate status
- External Product ID
- Created and updated timestamps
