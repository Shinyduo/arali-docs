## Overview

Returns a signal plus its **occurrences**: every time Arali recorded evidence for it. Each occurrence includes the root-cause classification (`triggerType`), urgency, recoverability, the extracted evidence, and the interaction it came from. Use this to show *why* a company is at risk.

Requires the `signals:read` scope (`companies:read` is also accepted).

<Note>
For interactions marked **private**, the interaction's `title`, `summary` and transcript are returned as `null`. The occurrence and its evidence are still returned.
</Note>

## Path Parameters

<ParamField path="id" type="string" required>
  Signal UUID
</ParamField>

## Query Parameters

<ParamField query="includeTranscripts" type="boolean" default="false">
  If `true`, include the first 1,000 characters of each linked interaction's transcript
</ParamField>

<ParamField query="occurrenceLimit" type="integer" default="20">
  Maximum occurrences to return, most recent first (1–100)
</ParamField>

## Example Request

```bash
curl "https://api.arali.ai/api/v1/signals/0fd50a03-664c-440a-894e-3c64cdb72e48?includeTranscripts=true" \
  -H "Authorization: Api-Key YOUR_API_KEY"
```

## Error Responses

| Status | Description |
|--------|-------------|
| `400`  | `id` is not a UUID |
| `401`  | Missing or invalid authentication |
| `403`  | Insufficient permissions (requires `signals:read` or `companies:read`) |
| `404`  | Signal not found, or not visible to this API key |
