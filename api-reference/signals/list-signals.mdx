## Overview

Arali watches your calls, meetings, emails and tickets and raises **signals** on companies: churn and contraction **risks**, expansion **opportunities**, and **info** alerts. Each signal has a type, category, severity, status and owner.

Requires the `signals:read` scope (`companies:read` is also accepted). If the API key's creator only has access to some companies, only signals on those companies are returned.

<Note>
Arali creates a separate signal row each time it detects the same issue again. Rows describing the same issue share a `dedupeKey` — group by it to show one issue with a "×N" count.
</Note>

## Query Parameters

<ParamField query="companyId" type="string">
  Only signals on this company (UUID)
</ParamField>

<ParamField query="accountId" type="string">
  Only signals on this account (UUID)
</ParamField>

<ParamField query="status" type="string">
  One or more of `open`, `in_progress`, `resolved`, `dismissed`, `reopened` (comma-separated). Returns all statuses if omitted.
</ParamField>

<ParamField query="type" type="string">
  One or more of `risk`, `opportunity`, `info` (comma-separated)
</ParamField>

<ParamField query="severity" type="string">
  One or more of `low`, `medium`, `high`, `critical` (comma-separated)
</ParamField>

<ParamField query="categoryKey" type="string">
  One or more category keys, comma-separated (e.g. `churn`, `contraction`, `expansion`)
</ParamField>

<ParamField query="ownerUserId" type="string">
  Only signals owned by this user (UUID)
</ParamField>

<ParamField query="unassigned" type="boolean">
  `true` returns only signals with no owner; `false` returns only signals with an owner
</ParamField>

<ParamField query="overdue" type="boolean">
  `true` returns only signals past their `dueAt` that are not resolved or dismissed
</ParamField>

<ParamField query="firstSeenAfter" type="string">
  Only signals first seen on or after this date (`YYYY-MM-DD`)
</ParamField>

<ParamField query="firstSeenBefore" type="string">
  Only signals first seen on or before this date (`YYYY-MM-DD`)
</ParamField>

<ParamField query="lastSeenAfter" type="string">
  Only signals last seen on or after this date (`YYYY-MM-DD`)
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page (1–200)
</ParamField>

## Example Request

```bash
curl "https://api.arali.ai/api/v1/signals?companyId=eea7ade2-7470-4134-844c-11a0934f9cb2&status=open,in_progress,reopened" \
  -H "Authorization: Api-Key YOUR_API_KEY"
```

## Error Responses

| Status | Description |
|--------|-------------|
| `400`  | Invalid filter value (unknown enum, malformed UUID or date) |
| `401`  | Missing or invalid authentication |
| `403`  | Insufficient permissions (requires `signals:read` or `companies:read`) |
