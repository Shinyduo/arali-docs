---
title: 'Arali API: Get a Support Ticket with Its Message History'
api: 'GET /api/v1/tickets/{id}'
description: 'Get one Arali support ticket with the REST API, including its status, source system, participants and full message history with sender and direction.'
---

## Overview

Returns a ticket, the people on it, and every message in order. Requires the `tickets:read` scope (`interactions:read` is also accepted).

## Path Parameters

<ParamField path="id" type="string" required>
  Ticket UUID. The ticket's `interaction_id` is also accepted.
</ParamField>

## Example Request

```bash
curl "https://api.arali.ai/api/v1/tickets/1c76d2e5-38f7-4f40-83d3-6243c9babddd" \
  -H "Authorization: Api-Key YOUR_API_KEY"
```

## Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid authentication |
| `403`  | Insufficient permissions (requires `tickets:read` or `interactions:read`) |
| `404`  | Ticket not found, or not visible to this API key |
