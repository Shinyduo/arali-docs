## Overview

Returns support tickets synced into Arali from your helpdesk (Freshdesk, Jira, tawk.to and others), most recently active first.

Requires the `tickets:read` scope (`interactions:read` is also accepted). If the API key's creator only has access to some teams, only tickets in those teams are returned.

<Tip>
To find tickets **waiting on your team**, look for open or pending tickets where `last_message_direction` is `inbound` — the customer wrote last.
</Tip>

## Query Parameters

<ParamField query="accountId" type="string">
  Only tickets linked to this account (UUID). Comma-separate or repeat for several. Also accepts `account_id`.
</ParamField>

<ParamField query="accountExternalId" type="string">
  Only tickets linked to the account with this external ID (your own ID, matched case-insensitively). Also accepts `externalAccountId`.
</ParamField>

<ParamField query="companyId" type="string">
  Only tickets linked to this company (UUID). Comma-separate or repeat for several. Also accepts `company_id`.
</ParamField>

<ParamField query="companyExternalId" type="string">
  Only tickets linked to the company with this external ID (matched case-insensitively). Also accepts `externalCompanyId`.
</ParamField>

<ParamField query="status" type="string">
  One of `open`, `pending`, `resolved`, `closed`, `archived`, `spam`
</ParamField>

<ParamField query="search" type="string">
  Case-insensitive match on subject or description. Also accepts `q`.
</ParamField>

<ParamField query="provider_key" type="string">
  Only tickets from this source system, e.g. `freshdesk`. Also accepts `providerKey`.
</ParamField>

<ParamField query="start_date" type="string">
  Start of the activity window (ISO 8601). Must be used with `end_date`.
</ParamField>

<ParamField query="end_date" type="string">
  End of the activity window (ISO 8601). Must be used with `start_date`.
</ParamField>

<ParamField query="date_range" type="string">
  Shortcut for recent activity, e.g. `7d` or `30d`. Ignored when `start_date` and `end_date` are set.
</ParamField>

<ParamField query="org_unit_id" type="string">
  Only tickets in these teams (UUIDs). Repeat or comma-separate.
</ParamField>

<ParamField query="user_id" type="string">
  Only tickets where these users participate (UUIDs). Repeat or comma-separate.
</ParamField>

<ParamField query="participant_only" type="boolean">
  If `true`, only tickets where the API key's creator is a participant
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page (1–100)
</ParamField>

## Example Request

```bash
curl "https://api.arali.ai/api/v1/tickets?company_id=eea7ade2-7470-4134-844c-11a0934f9cb2&status=open" \
  -H "Authorization: Api-Key YOUR_API_KEY"
```
