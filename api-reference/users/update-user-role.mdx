---
title: 'Assign Workspace User Role'
api: 'PUT /api/v1/users/{userId}/role'
description: 'Assign one of the five standard roles and optional team membership to a workspace user'
---

**Required scope:** `users:update`

## Path Parameters

<ParamField path="userId" type="string" required>
  UUID of an existing workspace member.
</ParamField>

## Request Body

```json
{
  "role": "manager",
  "team_ids": ["8c12d955-79c0-4edf-9b04-216d11a2901c"]
}
```

`role` is required and must be one of `owner`, `admin`, `manager`, `member`, or `viewer`. `team_ids` is optional; when omitted, the member's current teams are kept. `manager` and `viewer` roles require at least one team.

## Response

```json
{
  "user_id": "b4e14efb-7d7e-4f64-9659-dd1bd032808a",
  "role": "manager"
}
```

The update revokes the member's existing sessions. Common errors include `user_not_found`, `invalid_role`, `role_not_configured`, `team_required_for_role`, and `team_not_found`.
